# FATIMA WindGuard

Application de détection des arrêts sans justification des turbines éoliennes.

Fonctionnalités :
- Analyse des données SCADA (AKHI)
- Analyse des alarmes (BRUTE MAI)
- Détection des arrêts suspects
- Croisement avec les alarmes
- Identification des arrêts justifiés et non justifiés
- Visualisation graphique des résultats
